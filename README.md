# Saransh Dhingra — Portfolio Website

A responsive portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and resume-based content
- `style.css` — responsive dark navy / teal design
- `script.js` — mobile navigation, current year, scroll reveal
- `profile.jpg` — optional personal photo (add your own image)

## Run locally
1. Keep all files in the same folder.
2. Add your own photo and name it `profile.jpg` (optional). Without it, the site displays an SD monogram placeholder.
3. Open `index.html` in a browser.

## Before publishing
- Verify phone and email details are still correct.
- Add actual GitHub / LinkedIn / project URLs only if you want them displayed; no unverified links are fabricated here.
- Project visuals are illustrative and are not screenshots of deployed applications.
- The page intentionally does not include a fake downloadable CV link or non-working project buttons.

## Publish
You can deploy the folder using GitHub Pages, Netlify, or another static hosting service.
